# D-935 — Exceção do protocolo para o atelier HTML com Quarks.js

> **Renumerada em 2026-11-06:** D-333 → D-935. O ID D-333 já pertence a outra decisão no `origin/main`; o conteúdo local foi preservado com o novo ID.


- Data: 2026-11-05
- Escopo: exclusivamente o protótipo HTML dos oito Moves da D-933.
- Estado: decisão aprovada; documentação local, publicação não realizada.

## Frase literal do criador

> Continuar no HTML com Quarks.js

Resposta à pergunta: “Para este pedido, o HTML com Quarks.js continua sendo a entrega, como exceção aos requisitos de Motion Composer e batalha Godot do novo protocolo, ou você quer mudar a entrega para Godot?”

## Decisão

A entrega permanece HTML com Quarks.js. Para este pedido, há exceção aos requisitos de construir sobre o Motion Composer e validar na batalha Godot. Preservar as demais regras: independência dos participantes, relógio único, inspeção das duas vistas, vídeo e aprovação artística. Nenhuma integração ao jogo Godot autorizada.

## Ambiguidades

Nenhuma sobre o formato da entrega. A regra de tamanho foi respondida separadamente na D-936.
